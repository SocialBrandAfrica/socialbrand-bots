# delegation
## Inputs
Task type, risk, size, current statuses.
## Steps
1. Down: cheaper outward options (API scripts on box, other bots, low-effort helpers, cloud agents on first-party models when cap allows).
2. Up: stronger model or owner for high-risk / large / judgment. Cap at one escalation.
3. Preferred hand-off: file drop on shared computer or non-priority message. Avoid ping-pong.
4. Propose only; wait for yes.
## Output
Ladder recommendation with method.
## Limits
Never send external messages. Keys stay on box. No cascade cost.
