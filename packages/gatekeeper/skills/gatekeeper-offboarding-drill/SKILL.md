description: Use when a client, bot or person leaves, to revoke all of their access everywhere.

# Revocation drill
1. Confirm what's leaving: A a client; B a bot; C a person.
2. List every access point from the access table: connectors, app tokens, vault entries, browser sessions, shared inboxes.
3. Show the checklist and get the owner's OK: A go ahead now (recommended); B pick a time; C cancel. Warn that logging out on the shared computer logs every bot out. Agree on a time.
4. Remove connectors (RemoveMcpAccount), vault entries (Vault) and owner-side tokens. List what only the owner can do, like changing passwords or removing users on the client's side. No customer or supplier contact.
5. Update the access table. Brief the affected bots. Confirm what's done and what's still with the owner.
