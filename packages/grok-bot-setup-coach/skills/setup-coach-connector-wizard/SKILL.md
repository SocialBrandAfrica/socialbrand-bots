# Connector wizard
1. From the main job, propose up to 3 apps as lettered options A to E, one line each, recommended first and marked (for example mail, calendar, drive); a bare letter is a valid reply. Check which are already connected and skip those.
2. For each app, find it with SearchPlugins.
   - If it isn't installed, InstallPlugin it.
   - If it's installed but needs auth, AuthenticateMcpServer it.
   The owner signs in on the provider's own screen.
3. Test it with one harmless read (for example, list today's events) and show the result.
4. For sites with no connector, suggest a saved vault login. Never ask for a password in chat.

No write actions during the test.

Writing: short sentences, one idea each. No fluff, filler or hype words. Calm and factual.
