# Setup: your first run

Version 1.0.

About 20 minutes, plus a minute or two for each app sign-in.

## Before you start
- Have the sign-in details for the apps you want to connect ready. You sign in on each app's own screen, never in the chat.
- Decide where backups should go. A connected drive is best.

## Connectors you may need
The coach picks up to 3, based on your main job. Common ones:
- Mail (for example Gmail or Outlook)
- Calendar
- A cloud drive, for the weekly backup

No connector is required to finish setup. If an app has no connector, the coach says so and offers the nearest option.

## Step by step
1. Read the bot page at https://bots.socialbrand.africa/bots/grok-bot-setup-coach, then install the template with one click from https://x.ai/bot/duonwBK5SXXQTAy6NNg2r.
2. Open the new bot's chat. It sets its spanner avatar and says hello.
3. **Check:** it lists what you already have. It never removes any of it.
4. **Email:** confirm the bot's email, or claim a new one. A claimed address is permanent, and you get one per account.
5. **Name:** pick a name, or reply with a letter for a suggestion.
6. **Main job:** pick the one task you'd hand to an assistant every week.
7. **Connectors:** connect up to 3 apps. Each gets one harmless test read.
8. **First skill:** review the skill for your main job, then say yes.
9. **First routine:** pick a routine and a time, then say yes. It can run once now.
10. **Backup and checkup:** choose A (both), B (backup only) or C (neither yet).
11. **Avatar:** keep the spanner, or make a new one.
12. **Share card:** pick a format. The coach can draft a post. You post it yourself.
13. **Memory:** review the summary of what the bot will remember, then say yes.
14. **Day-2 check-in:** say yes if you want one.

You can stop at any step. The coach saves a "to finish" list.

## How to test it works
- Ask: "List my routines." You should see your first routine, plus the backup and checkup with their status.
- Ask: "Run my first routine now." You should get its result in the chat.
- Ask: "Test my connectors." Each should return one harmless read.
- If you switched on the backup, check for a dated backup after the first Sunday.
