# Troubleshooting: top 5 failures and fixes

## 1. A connector won't sign in, or its test read fails
- Ask the coach to connect it again. Sign in on the app's own screen.
- If it still fails, skip it. The coach adds it to your "to finish" list.

## 2. The avatar didn't appear
- Image generation can fail. The coach carries on and puts the avatar on the "to finish" list.
- Ask: "Set your avatar now."

## 3. A routine didn't run
- Both shipped routines start paused. Ask: "List my routines" to check their status.
- Ask: "Resume the weekly backup" (or the checkup) to switch one on.
- Runs can start up to 15 minutes early or late.

## 4. The backup didn't save
- The backup only messages you when it fails, so read that message for the reason.
- Check that your drive connector is still signed in. Ask the coach to test it.
- Without a drive, backups go to a dated file on the bot's computer.

## 5. The email name I wanted is taken
- The coach checks availability before claiming. Pick another suggestion or type your own.
- If the bot already has an email, the coach confirms it instead. It's permanent, one per account.

Still stuck? Run the monthly checkup now: ask "Run the setup checkup."
