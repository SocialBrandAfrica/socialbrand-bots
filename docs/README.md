Internal working docs for the bots site and the bot rollout. This folder is not part of the public website: `.vercelignore` keeps it out of every Vercel deploy. The repo itself is public, so nothing secret or private goes here.

| [pm/status.json](pm/status.json) | Superseded by pm/status-v3.json, kept as history. Machine-readable workstream status |

| [foundry/recipe.md](foundry/recipe.md) | The bot creation recipe, Steps 0-12, run one step at a time |

| [pm/status-v3.json](pm/status-v3.json) | Status v3 (24-10-2026 09:30 SAST): done, deployed, in_progress, blocked and planned items |
